      Every downloaded quotation is also saved to Google Drive in folders by location and client. Each client folder has a Google Sheet with every product quoted to them (date, product, size, load class, discount, value), and a new row is added with each quotation. All quotations are also listed in a quotation register in the main folder.

      THERMODRAIN Quotations / CITY / CLIENT / CLIENT - client data       (Google Sheet)

      How to get the Client ID (one time, about 10 minutes)
      1. Open console.cloud.google.com with the company Google account and create a project, e.g. "THERMODRAIN Quotations".
      2. APIs & Services → Library → enable Google Drive API.
      3. APIs & Services → OAuth consent screen: choose External, fill the app name and email, add the scope …/auth/drive.file, add your staff emails as test users (or publish the app).
      4. APIs & Services → Credentials → Create credentials → OAuth client ID → Web application. Under Authorised JavaScript origins add your site address, e.g. https://your-site.netlify.app
      5. Copy the Client ID into the box above, tick the box, and press Connect Google Drive.

      The app can only see files it creates itself. To keep one shared database, everyone should connect with the same company Google account.
